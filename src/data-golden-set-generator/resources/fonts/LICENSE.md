# Giấy phép font

Tất cả font ở đây lấy từ [google/fonts](https://github.com/google/fonts), giấy phép SIL Open Font License 1.1 (cho phép dùng, sửa, phân phối lại kèm giấy phép). Đã chọn các font hỗ trợ đủ dấu tiếng Việt.

| File | Họ font | Dùng cho |
|---|---|---|
| `handwriting/Charm-Regular.ttf` | Charm | Chữ viết tay |
| `handwriting/DancingScript[wght].ttf` | Dancing Script | Chữ viết tay |
| `handwriting/Itim-Regular.ttf` | Itim | Chữ viết tay |
| `handwriting/Mali-Regular.ttf` | Mali | Chữ viết tay |
| `print/Tinos-*.ttf` | Tinos (tương thích số đo Times New Roman) | Chữ in trên biểu mẫu |
| `print/Cousine-*.ttf` | Cousine (tương thích Courier New) | Chữ đánh máy trên giấy tờ cũ |
| `print/Arimo[wght].ttf` | Arimo (tương thích Arial) | Chữ in trên thẻ căn cước |

Toàn văn giấy phép: https://openfontlicense.org/open-font-license-official-text/
